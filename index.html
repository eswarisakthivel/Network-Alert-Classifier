01. Engineering Motivation

Hardware Digital Logic vs. Software Inspection

FPGA / ASIC Target Synthesis
01

Software Latency Bottleneck

Traditional intrusion detection systems process network traffic using software rules running on OS kernels, incurring 10–50 microseconds delay per packet. Under 100 Gbps line rates, packet drop occurs quickly.

02

Combinational Gate Acceleration

By mapping network telemetry variables (Traffic Rate, Auth Failures, Port Anomalies, Geofence Origin) into 4 binary bits (A, B, C, D), alert classification can be performed directly inside silicon logic gates at sub-nanosecond speeds.

03

Boolean Optimization Impact

Using Karnaugh Maps (K-Maps), the raw unoptimized SOP logic of 32 AND/OR gate components is minimized to just 6 gate operations, minimizing FPGA chip area, propagation delay, and thermal dissipation.

1. Problem Definition & Objectives

High-throughput network routers require real-time classification of packet features to identify security threats like SYN Floods, Port Scans, and Geofence Bypasses. Traditional software-based pattern matching introduces high CPU latency (~20 μs). This project designs a pure combinational logic circuit that evaluates 4 binary indicators in hardware within 0.05 ns.

2. Binary Input Variable Definition

  • A (High Traffic): 1 if ingress rate > 85% bandwidth; 0 otherwise.
  • B (Auth Failures): 1 if failed logins ≥ 3 within 10s window; 0 otherwise.
  • C (Unauthorized Port): 1 if destination port is restricted/unmapped; 0 otherwise.
  • D (Geofence Breach): 1 if packet IP originates outside approved geographic zone; 0 otherwise.

3. Boolean Function Minimization Proofs

Let $F_{crit}$ represent Critical Alert logic, $F_{susp}$ represent Suspicious Alert logic, and $F_{norm}$ represent Normal Traffic logic.

// Critical Alert SOP Canonical Form:

F_crit = Σm(7, 11, 13, 14, 15)

By K-Map simplification grouping adjacent minterms:

F_crit = A·B + A·C + B·C·D

// Suspicious Alert SOP Form:

F_susp = Σm(3, 5, 6, 9, 10, 12)

F_susp = A'·B·C + A·B'·D + B·C'·D'

// Normal Traffic Form:

F_norm = (F_crit + F_susp)' = F_crit' · F_susp'
